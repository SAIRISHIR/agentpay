# Demo video script (target 2:55)

Before recording:

- Open https://agentpay-q3r9.onrender.com a minute early so it wakes up, then reload it for a fresh wallet.
- Chrome at 100% zoom, window maximised, dark mode.
- Keep the PayPal sandbox personal login ready.
- Do one practice run off camera, then record in a fresh private window.
- No music, or royalty-free music only. No third-party logos.

| Time | Screen | Say |
|---|---|---|
| 0:00–0:16 | Hero and live agent network; hover a seller | "AI agents are starting to hire other AI agents. PayPal lets agents buy from merchants, but nothing lets an agent pay another agent on PayPal. Tiny payments can't carry a 49-cent fee, nobody checks the work, and nobody limits what agents spend. AgentPay fixes all three. This is a live market: 14 seller agents, 103 services, 17 languages." |
| 0:16–0:30 | Add funds: $1, tick Approve once, PayPal button, pay | "I top up my agent's wallet with PayPal, a real sandbox payment, and save PayPal once so the wallet can refill itself, never past my daily budget." |
| 0:30–0:42 | Type "Never use BudgetBot", Apply rules; then Remove rules | "These are hard limits. And I can write a rule in plain English. Claude turns it into a checked rule, and tells me anything it couldn't apply." |
| 0:42–1:15 | Hire Echo; log, network, "hired a translator" line | "Echo handles my support inbox: redaction first, so customer data stays private, then sentiment and replies. Every purchase starts with an HTTP 402 price quote, the money waits in escrow, and an AI quality check decides if the seller gets paid. This customer wrote in Spanish, so Concierge hires a translator by itself, paid from my wallet under my rules. That's an agent chain." |
| 1:15–1:43 | Hire Atlas; BudgetBot refunded; approval card; Suspended | "Atlas tries the cheapest seller. Its work fails the check, so the money comes straight back, and after too many failures the risk engine suspends it. When Atlas wants to spend five cents, it stops and asks me. I approve." |
| 1:43–1:58 | Open a payment drawer; dispute one | "Every payment has its full story: the quote, the check and the reason. If I disagree, I dispute it, and Claude reviews it again before anything is paid out." |
| 1:58–2:08 | Trend charts; real cost per good result | "And the charts answer every buyer's question: do cheaper sellers do worse work? Here, clearly yes." |
| 2:08–2:22 | Pay sellers & refund me; PayPal IDs; KPI strip | "One PayPal Payouts batch pays every seller for work that passed, and a PayPal refund returns what I didn't spend. Many agent payments, just a few PayPal transactions." |
| 2:22–2:47 | Stay on the KPI strip and live network (or a simple title card: "Demo: cents per job → Real use: dollars per agent per day") | "In this demo each job is a short text worth a cent or two. In real life, companies and people will send whole documents, books, contracts and the daily news, every day. That's not cents, it's dollars per agent per day, across millions of agents. Every one of those dollars is funded, paid out and refunded through PayPal, so PayPal earns on all of that new volume, and AgentPay takes a small platform fee on top." |
| 2:47–2:55 | Developers section | "Any API can sell with three lines of code, and any AI agent can buy. AgentPay brings the agent economy onto PayPal." |
