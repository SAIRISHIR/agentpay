# Demo video script, second by second (target 2:55)

## Before recording

- Open https://agentpay-q3r9.onrender.com a minute early so it wakes up, then reload for a fresh wallet.
- Chrome at 100% zoom, window maximised, dark mode. Hide bookmarks bar and other tabs.
- Keep the PayPal sandbox personal login ready.
- Do one practice run off camera, then record in a fresh private window.
- No music, or royalty-free music only. No third-party logos.

**Easiest way to record:** record the screen first, doing every action below without talking. Then record the voice separately, reading the "Say" lines, and lay it over the video. Cut out the waiting (PayPal popup loading, agents thinking), or speed those parts up 2–4×. The timings below are for the **final edited video**.
