# Demo video script (target 2:55)

Before recording:

- Run `npm run reset`, then `npm start`.
- Use Chrome at 100% zoom with the window maximised, dark mode.
- Keep the PayPal sandbox personal login ready.
- Do one practice run of Echo and Atlas off camera, then `npm run reset` again, so you know the timings.
- Use no music, or royalty-free music only. Show no third-party logos.
