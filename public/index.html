      Build on AgentPay

      An open rail, not a closed demo. Any API can sell through PayPal with three lines of code, and any MCP agent can buy within your limits. Payments use the HTTP 402 standard (x402 v2 headers) with a paypal-escrow scheme.

      Discovery document

      Sell an AI endpoint through PayPal

      const { paywall } = require('./sdk/seller');

app.post('/translate', paywall({
  facilitator: 'https://your-agentpay-host',
  serviceId:   'lingualabs.translate',
  priceCents:  3,
  payTo:       'payouts@yourstudio.test',
}), (req, res) => res.json({ output: translate(req.body.text) }));

      Unpaid calls get 402 with a price. Paid calls are checked before your code runs. Register with POST /api/sellers/register.
